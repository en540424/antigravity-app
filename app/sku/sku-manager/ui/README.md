UI コンポーネント一覧（sku-manager/ui）

- `card.tsx` : 立体カードスタイル（一覧性重視）。メイン推奨。
- `simple.tsx` : シンプルで読みやすい白背景のカードスタイル。
- `compact.tsx` : 最小表示のコンパクト版（軽量）。※本プロジェクトでは `simple` と似ているため統合を検討。
- `flat.tsx` : フラットなカードデザイン。`simple` と見た目が近い場合あり。
- `full-card.tsx` : 詳細表示寄りのカード。高情報密度。
- `hightech.tsx` : ハイテク風の装飾付きデザイン。
- `mobile.tsx` : モバイル最適化カードレイアウト。
- `current.tsx` : 現在のプロジェクト固有のUI（実験的）。
- `techDark.tsx` : ダークハイテク系の別バリエーション。

整理方針（提案）:
- 似たもの同士（`simple` / `flat` / `compact`）は用途別に残し、不要であれば削除または `deprecated` コメントを追加。
- 実際に使っているものを優先し、未使用コンポーネントは将来的に削除してコードベースを軽くする。

このREADMEは開発者向けのナビゲーション用です。
